# GeoMoz P0 — biblioteca Python e código R

## Âmbito
Correcções exclusivamente em `geolithicamz-hub/geomoz`.
A aplicação GeoMoz-Explorer não é alterada.

## Alterações
- Áreas geodésicas elipsoidais WGS84 com `pyproj.Geod`; funcionam para
  polígonos que atravessam o limite UTM 36S/37S, buracos e multipolígonos.
- `calculate_area` mantém a geometria/CRS originais.
- Filtros hierárquicos passam a respeitar a província seleccionada.
- Operações `link_*` de atributo evitam uma segunda coluna `geometry`.
- `read_*` rejeitam anos e versões `simplified=False` que não existem
  nos ficheiros actualmente indexados.
- Filtros geológicos inexistentes deixam de ser ignorados silenciosamente.
- O cliente R mantém a verificação TLS padrão e usa a nomenclatura de
  GeoPackages documentada pela biblioteca Python.

## Verificação
```bash
python -m pip install -e ".[dev]"
python -m pytest -m "not network" -q
```
São necessários testes adicionais com o repositório de dados Hugging Face
e validação em R. Não publicar automaticamente no PyPI.

## Compatibilidade
Foram adicionadas validações explícitas para opções previamente ignoradas,
incluindo `year` e `simplified`. Revisar consumidores antes do merge.
