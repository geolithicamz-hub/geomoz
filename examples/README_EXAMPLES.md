# 📚 Exemplos GeoMoz para Geólogos e Geocientistas

Esta pasta contém exemplos completos e tutoriais para geólogos, geocientistas e pesquisadores usarem GeoMoz em suas análises.

## 🗂️ Lista de Exemplos

### 1. 🗺️ [01_basic_geological_map.py](01_basic_geological_map.py)
**Mapa Geológico Básico de Moçambique**

Demonstra como criar mapas geológicos profissionais usando GeoMoz + Cartopy.

**Recursos:**
- Mapa geológico completo de Moçambique
- Cores geológicas padronizadas
- Features geográficas (relevo, oceanos, rios)
- Legendas personalizadas
- Seção geológica transversal

**Arquivos gerados:**
- `mozambique_geological_map.png`
- `mozambique_geological_cross_section.png`

## 🚀 Como Usar os Exemplos

### Instalação de Dependências

```bash
# Instalar GeoMoz
pip install geomoz

# Instalar dependências adicionais para exemplos
pip install cartopy matplotlib seaborn scipy
```

### Executar um Exemplo

```bash
# Navegar para a pasta de exemplos
cd examples

# Executar um exemplo específico
python 01_basic_geological_map.py
```

### Executar Tutorial Completo

```bash
# Executar tutorial passo a passo
python 06_complete_geologist_tutorial.py
```

## 📝 Notas

- Todos os exemplos usam dados reais de Moçambique
- Mapas de ocorrências minerais usam dados simulados para demonstração
- Dados reais de mineração devem ser integrados de fontes oficiais (INAMI, MIREME)
- CRS: WGS84 (EPSG:4326) para visualização, UTM para cálculos precisos
