RESUMO

O acesso a dados geoespaciais de qualidade é fundamental para a pesquisa científica, planejamento territorial, exploração de recursos naturais e gestão ambiental em Moçambique. No entanto, a disponibilização desses dados de forma integrada e acessível permanece um desafio para geocientistas, pesquisadores e profissionais do setor. Apresentamos o GeoMoz, uma biblioteca open-source desenvolvida nas linguagens Python e R, que democratiza o acesso a dados geoespaciais de Moçambique, incluindo divisões administrativas (11 províncias, 161 distritos, 459 postos administrativos e 11.524 localidades) e dados geológicos completos (~50.000 feições).

O GeoMoz foi concebido seguindo o modelo do consagrado pacote geobr (Brasil), adaptado às especificidades moçambicanas. A biblioteca integra-se automaticamente com a plataforma Hugging Face para download dos dados, implementa sistema de cache inteligente para uso offline, e oferece funções de visualização com suporte a matplotlib (Python) e ggplot2 (R). A arquitetura modular permite filtragem por código ou nome de província, distrito, posto administrativo e localidade, facilitando análises espaciais precisas.

Disponível via PyPI (Python) e em processo de submissão ao CRAN (R), o GeoMoz elimina barreiras técnicas no acesso a dados geoespaciais, promovendo a transparência e acelerando pesquisas em geologia, mineração, gestão de recursos hídricos e planejamento urbano. A ferramenta é particularmente relevante no contexto dos Objetivos de Desenvolvimento Sustentável (ODS), apoiando decisões baseadas em evidências para o desenvolvimento sustentável dos recursos minerais e gestão territorial de Moçambique.

Palavras-chave: Dados geoespaciais, SIG, Moçambique, Python, R, Open-Source, Geologia, Recursos Naturais


GEOMOZ: AN OPEN-SOURCE LIBRARY FOR ACCESSING GEOSPATIAL DATA FROM MOZAMBIQUE

ABSTRACT

Access to quality geospatial data is fundamental for scientific research, territorial planning, natural resource exploration, and environmental management in Mozambique. However, making this data available in an integrated and accessible way remains a challenge for geoscientists, researchers, and sector professionals. We present GeoMoz, an open-source library developed in Python and R languages that democratizes access to Mozambican geospatial data, including administrative divisions (11 provinces, 161 districts, 459 administrative posts, and 11,524 localities) and complete geological data (~50,000 features).

GeoMoz was designed following the established geobr package model (Brazil), adapted to Mozambican specificities. The library automatically integrates with the Hugging Face platform for data download, implements an intelligent cache system for offline use, and offers visualization functions with matplotlib (Python) and ggplot2 (R) support. The modular architecture allows filtering by code or name of province, district, administrative post, and locality, facilitating precise spatial analyses.

Available via PyPI (Python) and in the process of CRAN submission (R), GeoMoz eliminates technical barriers in accessing geospatial data, promoting transparency and accelerating research in geology, mining, water resource management, and urban planning. The tool is particularly relevant in the context of the Sustainable Development Goals (SDGs), supporting evidence-based decisions for the sustainable development of mineral resources and territorial management in Mozambique.

Keywords: Geospatial data, GIS, Mozambique, Python, R, Open-Source, Geology, Natural Resources
